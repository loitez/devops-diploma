# Дипломный проект DevOps

## Об устройстве репозитория
- `.github/workflows/`: CI/CD пайплайны (GitHub Actions).
- `my-app-chart/`: Helm-чарт для деплоя приложения в Kubernetes.
- `main.tf`: IaC описание инфраструктуры в Yandex Cloud (VPC, K8s, Registry).
- `app.py` и `Dockerfile`: Исходный код приложения и инструкции по сборке.

## Как развернуть инфраструктуру
1. Настроить S3-бакет для хранения terraform.tfstate.
2. Инициализировать Terraform: `terraform init`.
3. Применить конфигурацию: `terraform apply`.

## Как развернуть приложение
Развертывание происходит автоматически при каждом `git push` в ветку `main` благодаря GitHub Actions. Пайплайн выполняет сборку Docker-образа, отправку его в Container Registry и обновление релиза в кластере через Helm.

## Мониторинг и логирование
- **Логи**: Собираются автоматически через `master_logging` в облачную группу логов Yandex Cloud Logging.
- **Мониторинг**: Базовые метрики доступны в консоли Yandex Cloud в разделе Managed Service for Kubernetes.

## Релизный цикл
Используется GitFlow. Каждому образу присваивается тег, равный `SHA` коммита в Git, что обеспечивает полную прослеживаемость артефактов.
